V6.0.0 — CLEAN REWRITE

This release is a fresh implementation of the application core.
Old V4/V5 JavaScript was not copied into the new app.

NEW:
- Fresh HTML/CSS/JavaScript structure.
- Single local persisted state.
- Unique Bill ID + Bill Number handling.
- Persistent bill create/update/delete.
- Delete tombstones prevent deleted bills returning.
- Credit/EMI balances are derived from bills and payments.
- EMI schedule is informational and does not create duplicate credit entries.
- Payment receipt is attached to the exact bill payment.
- Repair jobs with save/edit/delete/history and current-date default.
- Inventory basics.
- JSON backup and explicit restore.
- Print uses the same invoice markup as the invoice preview.
- No automatic cloud restore or stale Firebase listener in the clean core.

INTENTIONALLY NOT INCLUDED:
- Legacy Firebase sync code.
- Legacy auto-save-on-close/history behavior.
- Legacy duplicate patch layers.
- Legacy recovery writers.
